## 🚀 Featured Projects

### 🧠 HealthPal — AI-Powered Fitness & Nutrition Backend

A backend platform for nutrition tracking, workout analytics, and AI-assisted user insights.

The project is designed as a **modular monolith using Spring Modulith**, with an emphasis on reliable background processing, external integrations, and fault-tolerant AI workflows.

**Highlights:**

- **🤖 AI Integration:** Integrated AI providers through Spring AI for AI-assisted fitness and nutrition features.
- **🔄 Model Fallback:** Implemented configurable provider fallback, attempt limits, and cooldown handling for resilient AI requests.
- **⚙️ Background Processing:** Built PostgreSQL-backed jobs with idempotency keys, transactional task claiming, processing leases, and bounded retries.
- **🥗 FatSecret Integration:** Integrated the FatSecret API using OAuth for nutrition-related data.
- **💬 Telegram Integration:** Added Telegram-based functionality for interacting with the platform.
- **🔐 Security:** Implemented JWT-based authentication using Spring Security.
- **🗄 Database Migrations:** Managed PostgreSQL schema evolution with Flyway.

**Tech Stack:**  
`Java 21` · `Spring Boot 4` · `Spring Modulith` · `Spring AI` · `PostgreSQL` · `Flyway` · `Spring Security` · `Docker`

### 🎬 MediaBuddy — Microservices Media Platform

A backend-focused media platform built to explore distributed system design, asynchronous communication, search, caching, and media-related workflows.

The system uses a **microservice-based architecture** with dedicated services responsible for different parts of the platform.

**Highlights:**

- **🎥 Media Platform:** Backend APIs for media processing and user-facing media workflows.
- **⚡ Asynchronous Communication:** RabbitMQ-based communication between services.
- **🔍 Search:** Elasticsearch-powered search across media content.
- **🚀 Caching:** Redis for high-speed data access and caching.
- **🗄 Polyglot Persistence:** PostgreSQL and additional data stores depending on service responsibilities.
- **💬 User Interaction:** Backend workflows for ratings, watch history, search, and other user interactions.
- **🧪 Integration Testing:** Testcontainers for infrastructure-dependent tests.

**Tech Stack:**  
`Java 17` · `Spring Boot 3` · `RabbitMQ` · `PostgreSQL` · `Redis` · `Elasticsearch` · `Docker` · `Testcontainers`
